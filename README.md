# Интерактивные приложения по теории автоматов

Требуется Python **3.11 или новее**. Сторонние библиотеки не нужны.
Каждый из двух файлов приложения автономен: его можно скопировать и запустить
отдельно от остальных файлов проекта.

## Запуск

```sh
python3 /Users/aleksejpavlenko/Desktop/automata_theory/dfa_minimizer.py
python3 /Users/aleksejpavlenko/Desktop/automata_theory/regular_equations_solver.py
```

Программа запрашивает путь к CSV (без окружающих кавычек), показывает вход,
ждёт Enter, выполняет вычисление и сохраняет результат **рядом с входным файлом**.
После сохранения выводится абсолютный путь; последний Enter завершает работу.
Ошибочный путь или содержимое можно исправить повторным вводом.
Ctrl+C прерывает работу; завершение стандартного ввода закрывает программу.

Все CSV: UTF-8 (BOM допускается), разделитель — запятая. Поля с запятыми,
кавычками или переводами строк заключаются в двойные кавычки по правилам CSV.
Пустые строки не игнорируются: они считаются ошибкой структуры.
Начальные и конечные пробелы имён и заголовков удаляются.

## Минимизация ДКА

Пример: `/Users/aleksejpavlenko/Desktop/automata_theory/examples/dfa.csv`.

```csv
состояние,начальное,допускающее,a,b
q0,1,0,q1,q2
q1,0,1,q1,q2
q2,0,0,q2,q2
q3,0,1,q3,q2
```

- Первые три заголовка обязательны; остальные — символы алфавита.
- Имена состояний и заголовки непустые и уникальные. Символы алфавита не должны
  совпадать со служебными заголовками. Символ может быть многосимвольной меткой.
- Ровно одно начальное состояние. Флаги — строго `0` или `1`.
- Каждая ячейка перехода содержит имя существующего состояния.
  Неполные и недетерминированные автоматы не принимаются.
- Пустой алфавит допустим: оставьте только три служебных столбца.
- В примере `q3` недостижимо и удаляется.

### ДКА после детерминизации НКА

Основной формат для такого автомата — **множества состояний НКА**, например
`{A,D}`, `{B,C}`, `{C}`, `{D}`. Готовый пример:
`/Users/aleksejpavlenko/Desktop/automata_theory/examples/dfa_subsets.csv`.

```csv
состояние,начальное,допускающее,a,b
{AD},1,0,"{B,C}",{C}
"{B,C}",0,1,{D},{C}
{C},0,0,{C},{C}
{D},0,1,{D},{C}
```

`{AD}`, `{A,D}` и `{D,A}` — одно и то же состояние. Порядок элементов
нормализуется. В краткой записи без запятых буквенное содержимое разбивается
на отдельные символы. Многосимвольные элементы задаются через запятую:
`{q0,q1}`; `{q0}` — одно состояние, поскольку имя содержит цифру.
Для однозначности используйте однобуквенные имена или имена вида `q0`, `q1`.
Повторы элементов и некорректные скобки запрещены. `{}` — пустое подмножество;
если оно используется, для него тоже требуется строка переходов.
**Каждое поле с запятой обязательно заключается в двойные кавычки CSV.**

Начальное и допускающие состояния уже определены при детерминизации и задаются
флагами CSV. Программа не выполняет детерминизацию заново. Если все состояния
заданы множествами, результат сохраняет эти множества вместо обозначений `М0`.
Эквивалентные состояния объединяются в **класс множеств**, например
`{{B,C},{D}}`, а не в `{B,C,D}`. Вложенное обозначение сохраняет состав класса
и поддерживается при повторном чтении выходного CSV.
Для приведённого примера результат содержит `{A,D}`, `{{B,C},{D}}` и `{C}`.

Алгоритм Мура сначала удаляет недостижимые состояния, затем уточняет разбиение
по допускающему статусу и классам переходов до неподвижной точки. Новые состояния
для обычных имён нумеруются `М0`, `М1`, … обходом в ширину от начального.
Для множеств сохраняется состав классов, как описано выше. В консоли показывается
состав каждого класса. Время минимизации в худшем случае — O(|Σ|·|Q|²),
дополнительная память разбиения — O(|Q|·(|Σ|+1)).

Результат: `dfa_minimized.csv`, в том же формате, пригодном для повторного чтения.
Соответствие исходным состояниям и список удалённых состояний выводятся на экран.

## Регулярные уравнения

### Основной ввод: правила без заголовка

Файл `/Users/aleksejpavlenko/Desktop/automata_theory/examples/equations_rules.csv`:

```csv
S->1A|2S
A->a|eps
```

Каждая строка — одно правило (одна ячейка CSV), без заголовка. Переменные —
одиночные заглавные латинские буквы A–Z, терминалы — цифры, строчные буквы
и экранированные символы. Для всех используемых переменных нужны правила.
Повторять левую часть нельзя: объединяйте альтернативы через `|` или `+`.
Переменная может находиться только в конце слагаемого; коэффициенты могут
содержать скобки и звёздочку, например `(a|b)*A|eps`.
Литерал-заглавная буква экранируется: `\A`. Пустое слово — `eps` или `ε`,
пустой язык — `∅`. Чтобы записать буквальное слово eps, экранируйте e: `\eps`.
Правила вроде `S->aSb`, `S->AB` или `S->A*` отклоняются.

Вывод в консоли для примера:

```text
S=2*1(a+eps)
A=a+eps
```

В решении `+` означает объединение, `eps` — пустое слово.
Выходной CSV сохраняет два столбца `переменная,решение`.

### Дополнительный ввод: прежняя матрица коэффициентов

Пример: `/Users/aleksejpavlenko/Desktop/automata_theory/examples/equations.csv`.

Поддерживается **праволинейная система**:

```text
Xᵢ = Aᵢ₁X₁ | Aᵢ₂X₂ | … | AᵢₙXₙ | Bᵢ
```

Коэффициент всегда находится **слева** от переменной. Произвольные нелинейные
уравнения, например `X = aXb | XX`, этим форматом не представляются.

```csv
переменная,X,Y,свободный_член
X,a,b,ε
Y,∅,b,a
```

Это система `X = aX | bY | ε`, `Y = bY | a`. Например, её решение можно записать
как `Y = b*a`, `X = a*(ε|bb*a)`; программа может выдать эквивалентную запись.

- Первый заголовок — `переменная`, последний — `свободный_член`.
- Между ними — непустые уникальные имена всех переменных, отличные от служебных
  заголовков. Для каждой переменной обязательна ровно одна строка.
- Строки могут идти в любом порядке; порядок столбцов задаёт порядок исключения.
- В ячейках коэффициентов и свободных членов — регулярные выражения, не ссылки
  на переменные. Буква `X` в такой ячейке означает буквальный символ `X`.
- Пустые ячейки запрещены: используйте `∅` для пустого языка и `ε` для пустого слова.

### Синтаксис выражений

| Запись | Значение |
|---|---|
| `a` | Один буквальный символ |
| `ab` | Конкатенация |
| `a+b` или `a\|b` (без обратной косой черты) | Объединение |
| `a*` | Ноль или более повторений |
| `(ab)*` | Группировка и повторение |
| `eps` или `ε` | Пустое слово |
| `∅` | Пустой язык |
| `\*`, `\|`, `\ε`, `\∅`, `\\` | Буквальные служебные символы |

Приоритет: звёздочка, конкатенация, объединение. Неэкранированные пробелы
игнорируются, `\ ` задаёт буквальный пробел. Пустые группы и пропущенные операнды
запрещены. Обратная косая черта экранирует ровно следующий символ; `\n` —
буква `n`, а не перевод строки. Буквальный плюс задаётся как `\+`.
Точки, квадратные скобки и прочие символы
не имеют специального значения. Это **не синтаксис модуля Python `re`**.

Алгоритм исключает переменные по лемме Ардена, затем выполняет обратную подстановку.
Для `X = AX | B` выбирается `A*B`. Если ε принадлежит A, решение может быть
неединственным; приложение всегда вычисляет **наименьшее решение по включению
языков**. Циклы допустимы и не считаются ошибкой.

Деревья выражений упрощаются по тождествам с ε и ∅, повторяющиеся слагаемые
удаляются. Кратчайшая запись выражения не гарантируется. Размер результата может
расти экспоненциально; число матричных обновлений — O(n³), но операции над деревьями
не имеют постоянной стоимости. Очень большие системы могут исчерпать память,
а глубоко вложенные выражения — предел рекурсии; CLI сообщает об этом по-русски.

Результат: `equations_solution.csv` со столбцами `переменная,решение`.
Это формат результата, а не входной формат матрицы коэффициентов.

## Безопасное сохранение

Существующие файлы не перезаписываются. Если имя занято (включая каталог или
символическую ссылку), проверяются `_1`, `_2` и далее. Файл создаётся режимом `x`,
защищающим от одновременного выбора имени несколькими процессами. При ошибке
записи программа пытается удалить незавершённый файл. Устойчивость к отключению
питания и транзакционное сохранение здесь не гарантируются.

При работе с недоверенными CSV не открывайте результат в табличном редакторе
без отключения автоматической интерпретации формул: имена и литералы сохраняются
без изменения, в том числе если начинаются с `=`.

## Проверка

```sh
cd /Users/aleksejpavlenko/Desktop/automata_theory
python3 -m unittest discover -s tests -v
```

Тесты используют фиксированные генераторы случайных примеров. Для ДКА проверяются
совпадение языков на коротких словах и различимость всех пар состояний результата.
Для систем решение сравнивается с независимой итерацией на языках слов длиной
не более четырёх. Проверяются также синтаксис, ошибочные CSV, BOM, повторное чтение,
конкурентное создание выходных файлов и оба интерактивных сценария.
